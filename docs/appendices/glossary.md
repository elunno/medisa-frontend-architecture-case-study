# Appendix — Glossary

**Application state** — frontend-owned state that can outlive a component/route, such as current audio playback.

**Client state** — state whose source of truth is the current frontend runtime, including local UI/workflow state.

**Domain** — a coherent business responsibility with its own language, rules, and lifecycle.

**Entitlement** — a decision about whether a user may access a resource/capability under current policy.

**Server state** — remotely owned data that is fetched, cached, invalidated, and may become stale.

**State machine** — an explicit model of allowed states and transitions for a workflow/runtime.

**Promotion window** — time-limited access that can override normal premium restrictions for a defined period.

**Public feature API** — the intentionally exposed functions/components/types through which other parts of the frontend interact with a feature.

**Reference model** — simplified executable code that demonstrates architectural reasoning without reproducing proprietary production source.
